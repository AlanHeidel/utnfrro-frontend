Frontend del trabajo práctico de **Desarrollo de Software** de **UTN FRRo**.  
Este proyecto contiene la interfaz web de la aplicación y consume una API backend.

---

<p>
	<img src="https://img.shields.io/badge/Descripción-333333?style=for-the-badge" alt="Descripción">
</p>

La aplicación fue desarrollada para ofrecer una experiencia web moderna, con navegación entre vistas, manejo de estado y consumo de endpoints del backend.

